# 果冻擂台 Jelly Brawl

横屏果冻互撞。圆形平台会缩圈，吃果冻块变大，蓄力把别人挤下去。三局定胜负，总分并列就加赛。打开后先看到加载页，资源完成后进入大厅。

可以单机打三个 AI，也可以用 4 位房间码联机，2 到 6 人。房主的浏览器负责物理，其他人只发送摇杆和蓄力。

## 怎么玩

- 左半屏按住拖动是摇杆。电脑用 WASD 或方向键。
- 右下角「冲」，或键盘空格。按住蓄力，松开冲刺。
- 黄点升级，最高 3 级。被重击会掉一级，并掉出一块果冻。
- 糖果会从天上掉下来。同时只能拿一个：弹簧、护盾、磁铁、烟雾。
- 被淘汰后变成幽灵，每 10 秒可以在平台上点一下，放一块布丁挡住别人。
- 一局 60 秒。名次分是 4 / 2 / 1 / 0。淘汰前 3 秒内最后撞你的人额外 +1，自己滑出去不加。
- 打满 3 局。第一名并列就再打，直到只有一个冠军。
- 左上角可以静音。大厅可以选 6 种颜色和 6 种表情，选择会记在这台设备上。

## 本地运行

需要 Python 3。在项目目录执行：

```bash
python -m http.server 8080 --bind 0.0.0.0
```

电脑打开 http://127.0.0.1:8080 。不要用文件管理器直接打开 `index.html`。

手机和电脑连同一个 Wi-Fi，用电脑的局域网地址，例如 http://192.168.1.10:8080 。手机上的联机需要 HTTPS，见下面的部署。单机对战可以先用 HTTP。

调参面板只在 http://127.0.0.1:8080/?debug=1 出现。

## 部署到 GitHub Pages

仓库名用 `jelly-brawl` 时，页面会在 `https://用户名.github.io/jelly-brawl/`。资源都是相对路径，可以放在这个子路径下。

1. 把代码推到 `main`。
2. 仓库 Settings → Pages → Build and deployment 选 GitHub Actions。
3. `.github/workflows/pages.yml` 会在每次推送后发布当前目录。
4. 发新版本时，把 `sw.js` 里的 `CACHE_VERSION` 加 1。已经打开过的设备会看到「点击更新」。

## 加到主屏幕

iPhone（Safari）：

1. 用 Safari 打开部署后的地址。
2. 点底部分享按钮。
3. 选「添加到主屏幕」。
4. 之后从主屏幕图标进入，是独立全屏。

安卓（Chrome）：

1. 用 Chrome 打开同一地址。
2. 菜单里选「安装应用」或「添加到主屏幕」。
3. 安装后从图标进入。

## 已知限制

- 联机信令使用公共 tracker，不保证永远可用。连不上的网络需要自己填 TURN，说明在 `NETWORK_NOTES.md`。
- 客机不做本地预测，画面大约落后 50 毫秒，用来对齐房主快照。
- 房主掉线后，所有人回大厅。普通玩家掉线后，那只果冻交给 AI。
- 客机看得到撞击结果，粒子只在跑物理的那一台播放。
- iPhone 没有振动接口，重击振动会自动跳过。
- 必须在第一次触摸之后才有声音。
